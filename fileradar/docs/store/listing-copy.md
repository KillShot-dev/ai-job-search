## Description
FileRadar is a Finder companion for Mac. Browse shelves by kind, search with plain language, read text inside images on device, group downloads by source, and clean duplicates — without uploading your files.

**Browse**
• Home shelves for Images, Videos, Music, Documents, Archives, and Apps
• Grid, list, columns, and Showcase views
• Optional dual-pane and folder tabs when you need them
• Quick Look with the space bar

**Search**
• Plain-language filters for type, date, size, and download source
• On-device text recognition for images and PDFs
• Saved searches (full version)

**Clean up**
• Duplicate finder (identical and look-alike)
• Clean Up cards for old installers, forgotten downloads, and more
• Moves files to Trash only — never silent delete

**Privacy**
• Indexing and OCR stay on this Mac
• No analytics SDK
• Optional Muse chat is separate and only sends what you approve over HTTPS

**Full version**
• Free trial included
• Unlock once via Mac App Store purchase (restores on Macs with the same Apple ID)

FileRadar works alongside Finder. It does not replace Finder or require Full Disk Access. Add folders you want indexed; security-scoped bookmarks remember those grants.
